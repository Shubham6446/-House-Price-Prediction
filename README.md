# House Price Prediction with Linear Regression

## What this project does
- Loads a small practice housing dataset.
- Performs basic cleaning and EDA.
- Splits data into training and test sets.
- Trains a Linear Regression model.
- Evaluates it using MAE and R-squared.
- Predicts a price for a sample house.

## Setup and run
```bash
pip install -r requirements.txt
python house_price_model.py
```

The included dataset is synthetic practice data. Replace it with a suitable public housing dataset before presenting it as a portfolio project. Report the metrics printed by your own run; do not claim unverified accuracy.
